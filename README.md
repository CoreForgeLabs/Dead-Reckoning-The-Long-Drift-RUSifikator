# Dead Reckoning: The Long Drift — русификатор

Неофициальная русская локализация игры [Dead Reckoning: The Long Drift](https://store.steampowered.com/app/4557340).

Поддержать проект: **https://boosty.to/coreforgelabs**

## Структура репозитория

- `rusifikator/data/` — сами переведённые строки (текст UI, нарратив, имена персонажей и т.д.), в виде JSON/сопоставлений. Отсюда лаунчер берёт данные для патча.

### Что чем адресуется

| файл | ключ | значение |
|---|---|---|
| `narrative.json`, `labels.json`, `epilogue.json` | ключ строки из `locale/en/*.json` | русский текст |
| `remap_by_en.json` | **английский текст** из `strings.en.translation` | русский текст |
| `extra.json` | английский литерал, извлечённый из скомпилированных сцен | русский текст |
| `gdc_literal_fixes.json` | `{file, en, ru}` — литералы, которые патчатся прямо в `.gdc` | — |

Интерфейс адресуется по **английскому**, а не по русскому. Прежний `remap.json`
сопоставлял «русский, который сейчас в сборке» → «наш русский», и это ломалось
на каждом обновлении игры: русский текст в сборке правится постоянно (между
двумя соседними сборками изменилось 585 значений из 1336), английский —
почти никогда (0 из 1336 за то же обновление). Каждая запись, чей старый
русский сдвинулся, пропускалась молча, и интерфейс выходил наполовину
английским при формально успешном патче.
- `launcher/` — исходный код GUI-лаунчера, который подключает `rusifikator/data/` к скомпилированному exe игры.

## Как это работает

Игра на движке Godot 4 хранит текст в скомпилированном виде внутри исполняемого файла (embedded PCK). Лаунчер:

1. находит exe игры (автопоиск через Steam или вручную);
2. переписывает основную таблицу переводов "на месте" (сохраняя структуру бакетов/хэшей оригинала — часть строк собирается движком в рантайме и не адресуется по ключу);
3. регистрирует дополнительную таблицу переводов для строк, извлечённых из скомпилированных сцен;
4. патчит несколько строковых литералов прямо в скомпилированных `.gdc`-скриптах (шаблоны BBCode и пул имён колонистов, которые не проходят через `tr()`).

Подробности — в комментариях внутри `launcher/patcher_translation.py` и `launcher/patcher_gdc.py`.

## Сборка exe

```
pip install pyinstaller
pyinstaller --onefile --windowed --name RussifierLauncher \
  --add-data "launcher/assets/astronaut_ru.png;assets" \
  launcher/launcher_gui.py
```

Рядом со собранным `RussifierLauncher.exe` нужно положить папку `data` (копию `rusifikator/data/`) — лаунчер читает перевод из внешних файлов, а не из самого exe, чтобы обновлять текст без пересборки.
